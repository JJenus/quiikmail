# AGENTS.md

QuiikMail — a Nuxt 4 email client UI (mock data only; no backend yet).

## Commands

- Use **pnpm**, not npm (CI + `packageManager: pnpm@11.20.0`; README's `npm install` is stale). Do not touch `package-lock.json`.
- `pnpm dev` — dev server at http://localhost:3000
- `pnpm lint` / `pnpm typecheck` — the only checks; there is **no test suite**. `pnpm build` also verifies the compiled output.

## Gotchas

- `.nuxt/` is gitignored but generated by the `postinstall` (`nuxt prepare`). `tsconfig.json` and `eslint.config.mjs` both import from `.nuxt/`, so lint/typecheck fail until `pnpm install` (or `pnpm exec nuxt prepare`) has run.
- **Nuxt 4 layout**: all source lives under `app/` (pages, components, composables, plugins, services, types). `~` resolves to `app/`. No `server/` directory exists yet.
- `useMailStore` is a **module-level `reactive()` singleton** (`app/composables/useMailStore.ts:23`) — never create state inside the composable function body.
- Mock data is still wired directly: `useMailStore.ts:1` imports `mockMails`. The `$mail` service (`app/plugins/mailService.ts` → `app/services/mailService.ts`) is a stub and **not yet called by the store** — that swap is the pending API integration.
- The `MailService` interface and its methods are the agreed API contract — implement against it, don't change its shape casually.

## Style

- **Everything is a Nuxt UI component** (`UButton`, `UInput`, `UModal`, `UDropdownMenu`, `UDashboardGroup`, …). No hand-rolled buttons, inputs, modals, dropdowns, or scroll areas. All components live in `app/components/mail/`; the old `base/` split was removed.
- **Dark mode**: `@nuxtjs/color-mode` (bundled with `@nuxt/ui`, `.dark` class) — `preference: 'system'`, fallback light. Use **semantic tokens** (`bg-default`, `bg-elevated`, `text-default`, `text-muted`, `text-dimmed`, `text-highlighted`, `border-default`, `bg-primary`, `text-inverted`, …) instead of hardcoded slate/violet shades. `UColorModeButton` lives in the topbar.
- The shell is a `UDashboardGroup` inside a relative "card" container (page bg outside the card uses `bg-page-bg dark:bg-page-bg-dark`). Panels need `min-h-0!` to neutralize the base `min-h-svh`. The sidebar uses `unit="px"` + `storage-key="quiikmail-layout"` (resizable/collapsible).
- Compose is **two components in one file**: `UModal` (`class="hidden md:block"`, no trigger slot so `class` hits the content) + `UDrawer` (`direction="bottom"`, `class="md:hidden"`), both bound to `state.compose.open` via `:open` + `@update:open` → `closeCompose()`. Shared markup uses `createReusableTemplate` (requires explicit `import { createReusableTemplate } from '@vueuse/core'` — it is **not** auto-imported).
- ESLint stylistic: `commaDangle: never`, `braceStyle: 1tbs` (set in `nuxt.config.ts`, so don't override in `eslint.config.mjs`). Run `pnpm exec eslint . --fix` for auto-fixable style issues.
- Use the custom palette in `app/assets/css/main.css` (`--color-qm-50`…`--color-qm-900`, primary violet-600 `#7C3AED`, page bg `#EEE9FF` light / `#16122B` dark) instead of ad-hoc colors.
- Icons via `@iconify-json/lucide` + `@iconify-json/simple-icons`.
- Commits follow conventional style (`feat: ...`).
